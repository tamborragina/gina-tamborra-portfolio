GINA TAMBORRA — PORTFOLIO WEBSITE
=================================

Files
- index.html: site structure and fixed text
- style.css: visual design and responsive layout
- app.js: bilingual language switch and project cards
- assets/: image files extracted from the supplied portfolio PDF

Preview locally
Open index.html in a browser. Some browsers may restrict local image loading; if that happens, preview by uploading the folder to a static hosting service.

Edit
- Update text in index.html for biography, intro and footer.
- Project titles, captions, descriptions and image assignments are in app.js.
- Colours, typography, spacing and responsive behavior are in style.css.
- To replace a project image, upload the new image into assets/ and update its path in app.js.
- The language button switches between Italian and English. Project descriptions have separate Italian and English text.

Publish free
GitHub Pages can host a static HTML/CSS/JS site for free. Create a GitHub repository, upload the contents of this folder (not the ZIP itself), then enable Pages in the repository settings. The site uses no server-side code.
Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages

Notes
- The site is an initial prototype based on the supplied PDF. Check every image, credit, date, link and translation before publishing.
- Links to video/audio and the downloadable calendar have not yet been wired up because their destinations need to be confirmed.
- No custom domain or paid hosting is required for the first version.
